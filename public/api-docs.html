REST API · v1.0 · application/json

LittleSteps API

Documentație completă a interfețelor REST backend pentru aplicația de gestiune pediatrică LittleSteps.

Base URL: /api
Format: JSON
Auth: PHP Session
DB: SQLite 3
Versiune: 1.0.0

Autentificare prin Sesiuni PHP: După apelul POST /api/auth.php?action=login, serverul inițializează o sesiune PHP securizată. Cookie-ul de sesiune (PHPSESSID) este trimis automat de browser la toate cererile ulterioare. Nu este necesar niciun header Authorization.

Multi-Tenant: Toate resursele sunt izolate prin family_id, extras din sesiunea utilizatorului autentificat. Nu este posibil accesul cross-family.

🔐 Autentificare
POST /api/auth.php?action=register Creare cont nou ▶

Creează un cont nou în sistem. Primul utilizator înregistrat primește automat rolul admin; toți utilizatorii următori primesc rolul member.

POST /api/auth.php?action=login Autentificare ▶

Autentifică utilizatorul și inițializează o sesiune PHP securizată. Parola este verificată cu password_verify() față de hash-ul BCRYPT stocat.

{
  "email":    "ioana@example.com",
  "password": "parola_securizata"
}
// HTTP 200 OK
{
  "success":   true,
  "user_id":   1,
  "role":      "admin",
  "fullname":  "Alexa Ioana și Miron Andrei",
  "family_id": 1
}
200Sesiune creată · Cookie PHPSESSID setat
401Credențiale invalide
POST /api/auth.php?action=logout Deconectare ▶

Distruge sesiunea PHP curentă și invalidează cookie-ul PHPSESSID.

200Sesiune distrusă · utilizator deconectat

📁 Media, Export & Interoperabilitate
POST /api/media.php Upload imagine ▶
🔒 Necesită sesiune activă

Acceptă un upload de fișier imagine (multipart/form-data). Fișierul este stocat fizic în public/assets/uploads/ cu un ID unic bazat pe timestamp. Metadata (calea relativă) este salvată în tabela media.

Câmp FormTipObligatoriuDescriere
photofileDAFișier imagine (jpg/png/gif, max 5MB)
201{ success: true, path: "uploads/16857123.jpg" }
GET /api/export.php?format=json Export JSON ▶
🔒 Necesită sesiune activă

Generează și descarcă un fișier JSON cu toate activitățile copilului activ. Răspunsul este livrat cu Content-Disposition: attachment; filename=littlesteps_export.json.

200application/json · fișier descărcat automat
GET /api/export.php?format=csv Export CSV ▶
🔒 Necesită sesiune activă

Generează un fișier CSV tabelar cu toate activitățile, deschizibil direct în Excel / Google Sheets.

200text/csv · fișier descărcat automat
GET /api/rss.php Flux RSS 2.0 ▶

Endpoint public care generează un flux RSS 2.0 valid cu ultimele 20 activități. Poate fi consumat de orice agregator de știri. Nu necesită autentificare (acces public controlat).

200application/rss+xml · XML valid RSS 2.0
🛡️ Administrare Sistem
GET /api/admin.php Toți utilizatorii ▶
🔒 Necesită rol admin / family_admin

Returnează lista tuturor utilizatorilor din familia curentă, cu rolurile și emailurile asociate. Filtrarea se face automat după family_id din sesiune.

[
  {
    "id":       1,
    "email":    "ioana@example.com",
    "fullname": "Alexa Ioana și Miron Andrei",
    "role":     "admin"
  }
]
403Rol insuficient — acces interzis
DELETE /api/admin.php?id={userId} Șterge utilizator ▶
🔒 Necesită rol admin

Șterge definitiv un cont de utilizator din baza de date SQLite. Operația este ireversibilă. Adminul nu se poate șterge pe sine însuși.

Parametru URLTipObligatoriuDescriere
idintegerDAID-ul utilizatorului de șters
200{ success: true, message: "Utilizator șters" }
403Tentativă de auto-ștergere sau rol insuficient
